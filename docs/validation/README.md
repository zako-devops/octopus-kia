# Validation records

Dated, sanitized build/install and real start/stop receipts. No credentials, tokens,
VINs, account/device IDs or private phone IPs are included. The user confirmed
that charging both started and stopped. These API trials preceded the stop watch
menu; its complete start/stop flow passed offline emulator checks. Installation
success does not establish physical UI or multi-day reliability.

The build receipt records the earlier build verification before installation; the
separate install receipt confirms later deployment of the same SHA-256. These
public copies are evidence only, never live-operation fences. Original receipts
and trial state remain in ignored .local/.

The confirmation-icon build and installation receipts describe the later tick
update now installed on the watch. Earlier build/install receipts remain historical.
